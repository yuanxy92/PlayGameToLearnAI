# 项目设计总览

## 项目名称

《神经水厂》

## 面向对象

高中生、本科低年级学生，以及需要神经网络入门直觉的课程学习者。

这不是 K12 启蒙游戏，也不是纯娱乐手游。它更像课程伴随型 puzzle lab：学生一关一关解决水路问题，在操作中逐渐理解神经网络的基本结构。

## 核心隐喻

清溪镇有一座会思考的水厂。水厂需要根据山泉、井水、雨水槽等不同来水，调出合适的供水量。学生扮演水路值守员，通过安装、调节和记录水路，让供水池水位贴近目标黄线。

神经网络概念与水路隐喻的对应关系：

| 神经网络概念 | 游戏隐喻 |
| --- | --- |
| 输入 `x` | 水源流量 |
| 权重 `w` | 管道粗细 |
| 正权重 | 输水管 |
| 负权重 | 抽水管 |
| 偏置 `b` | 泵站基础水压 |
| 加权求和 | 合流池 |
| 输出 `y` | 供水池水位 |
| 目标值 | 供水池黄线 |
| 误差 | 当前水位与黄线的距离 |

## 第一章学习目标

第一章只讲清楚一件事：线性模型。

学生应在通关后理解：

```text
供水量 = 来水量 × 管道粗细 + 泵站水压
```

也就是：

```text
y = x × w + b
```

多个水源时：

```text
y = x1 × w1 + x2 × w2 + b
```

最后再给出大学里常见的写法：

```text
y = Xw + b
```

## 体验目标

- 像游戏，不像网页表单。
- 固定游戏坐标系，跨设备只做整体缩放。
- 学生主要通过点、拖、安装、调节、过关来学习。
- 数学符号不应过早出现，通关总结页再把游戏语言翻译成公式。
- 每一关只引入一个新概念。
- UI、视觉、动画和架构后续全部重新设计。

## 后续章节方向

第 2 章可以围绕激活函数设计：

- 止回闸：ReLU，负水位被挡住。
- 限流闸：clamp / hard sigmoid，把水位限制在范围内。
- S 形水门：sigmoid，输入越大输出越接近上限。
- 分流池：softmax，多出口之间按比例分水。

这些内容暂时只保留为方向，尚未进入正式关卡设计。
