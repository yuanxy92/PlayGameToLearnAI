# Play Game To Learn AI

一个面向高中生和本科低年级学生的 HTML5 + Phaser puzzle lab 原型：用修水管的方式学习神经网络的基础概念。

![神经水厂地图](assets/readme-screenshot.png)

## 项目简介

《神经水厂》把神经网络里的输入、权重、偏置和输出，改写成更像游戏的水路系统：

- 水源读数：输入 `x`
- 管道粗细：权重 `w`
- 泵站水量：偏置 `b`
- 供水池水位：输出 `y`

第一章的目标是让学生在闯关中理解线性模型：

```text
y = x × w + b
```

多个水源合流时：

```text
y = x1 × w1 + x2 × w2 + b
```

通关后会解锁“水路档案”，再把游戏语言翻译成高中公式，并在最后给出大学里常见的矩阵写法：

```text
y = Xw + b
```

## 当前内容

- Phaser 画布版通关地图：沿着青溪镇水路逐关前进，节点按解锁进度开放。
- 第 1 章：线性水路，共 7 个关卡。
- 游戏化控件：点击管道后在底部 HUD 调节，使用安装、拆除、加减、预设值来控制水路。
- 固定游戏坐标系：主画面按 390 × 844 设计，用 Phaser Scale.FIT 适配手机和桌面窗口，避免网页长条滚动。
- 通关总结：第 1 章完成后显示公式总结页。
- 第 2 章占位：闸门系统，计划引入激活函数，再逐步过渡到 softmax 分流。

## 本地运行

这个项目目前仍然是纯静态入口，可以直接打开 `index.html`。页面通过 CDN 加载 Phaser 3，所以首次打开需要网络。

推荐用本地服务器预览，资源加载更稳定：

```bash
python3 -m http.server 4002
```

然后访问：

```text
http://127.0.0.1:4002/
```

调试入口：

```text
http://127.0.0.1:4002/?play=1
```

直接打开某一关：

```text
http://127.0.0.1:4002/?play=1&level=7
```

地图截图入口：

```text
http://127.0.0.1:4002/?map=1
```
